1. ภาพรวมและหลักการทำงานของระบบ (How EduPlan Works)
--------------------------------------------------------------------------------
EduPlan AI เป็นเว็บแอปพลิเคชันประเภท Single Page Application (SPA) ทำงานบนบราวเซอร์ (Client-Side) 100% 
ไม่จำเป็นต้องมี Database หรือ Server สำหรับประมวลผลข้อมูลหน้าเว็บ ยกเว้นการเชื่อมต่อ Cloudflare Worker Proxy 
เพื่อเรียกใช้งาน AI (Google Gemini) โดยมีขั้นตอนการทำงานหลัก 4 ลำดับ:

[1] การรับข้อมูลเข้า (Input Layer):
    - มี 2 โหมดให้เลือก:
      * Step-by-Step Wizard: กรอกทีละขั้นตอน เหมาะกับผู้ใช้ทั่วไป
      * All-in-One Form: กรอกทุกหัวข้อในหน้าเดียว พร้อมคำนวณและพรีวิวแบบเรียลไทม์
    - ซิงก์ข้อมูลลง Reactive State กลางตัวเดียวกัน และบันทึกลง LocalStorage อัตโนมัติ ป้องกันข้อมูลสูญหาย

[2] ระบบจัดการหลักสูตร (Curriculum Engine):
    - โหลดฐานข้อมูลหลักสูตรแกนกลาง พ.ศ. 2551 (ฉบับปรับปรุง 2560) จาก public/data/curriculum.json 
      และแคชไว้ในหน่วยความจำ
    - ทำงานแบบ Cascading ตามลำดับชั้น:
      เลือกระดับชั้น (ป.1 - ม.6 / ปฐมวัย) -> กรองกลุ่มสาระวิชา -> ดึงมาตรฐานที่เกี่ยวข้อง -> แสดงตัวชี้วัดให้เลือก

[3] ระบบประมวลผล AI (AI Gateway & Prompt Engine):
    - ช่วยร่างจุดประสงค์การเรียนรู้ K (ความรู้), P (ทักษะ), A (เจตคติ) หรือสร้างแผนการสอนฉบับเต็ม
    - ยิง Request ผ่าน Cloudflare Worker Proxy (worker/worker.js) ซึ่งมีระบบ:
      * Waterfall Model Cascading: ลองโมเดลประสิทธิภาพสูงก่อน หากไม่พร้อมใช้งานจะไหลลงมาหาโมเดลสำรอง
      * Multi-Key Failover: หมุนเวียน API Key อัตโนมัติเพื่อไม่ให้ติดปัญหา Rate Limit 15 RPM
    - ระบบ Parser ฝั่งเว็บจะแยกวิเคราะห์คำตอบจาก AI แล้วเติมกลับเข้าช่องฟอร์มอัตโนมัติ

[4] การแสดงผลและส่งออกเอกสาร (Export & Preview Engine):
    - พรีวิว A4 เสมือนจริง: แก้ไขข้อความสดบนหน้าเว็บได้ (Contenteditable) พร้อมโหมดสั่งพิมพ์ที่ตัด UI ออก
    - ส่งออก Microsoft Word (.docx): สร้างโครงสร้างไฟล์ .docx 11 หัวข้อตามมาตรฐานราชการไทย 100% 
      ผ่านไลบรารี docx (ล็อกระยะขอบ 1 นิ้ว, ฟอนต์ TH SarabunPSK 16pt, ตารางพอดีหน้ากระดาษ)
    - คัดลอกลงคลิปบอร์ด (Rich-Text): แปลงเป็น HTML ตารางที่สามารถ Paste ลงใน MS Word ได้ทันที

กลุ่มที่ 1: ไฟล์หลักที่มีผลต่อการทำงานของเว็บ (Core Production Files - ห้ามลบ)
--------------------------------------------------------------------------------
- index.html
  * ไฟล์ HTML หลักของเว็บ บรรจุโครงสร้างหน้าจอทั้งหมด (Wizard, All-in-One, Modals, พรีวิว A4)
  * มีแท็ก Preload ฟอนต์ TH Sarabun และเรียกใช้งาน src/main.ts

- src/main.ts
  * สมองหลักของระบบ: ควบคุม State ทั้งหมด, จัดการ Event ปุ่มกด, การสลับแท็บ/โหมด, 
    การเลือกตัวชี้วัด, การยิง AI, และประสานงานระหว่างแต่ละโมดูล

- src/curriculum.ts
  * โมดูลจัดการหลักสูตร: โหลด curriculum.json, ค้นหาตัวชี้วัด, คัดกรองตามระดับชั้น/กลุ่มสาระ

- src/templates.ts
  * โมดูลสร้าง Prompt ให้ AI, ตัวแปลงผลลัพธ์ (Parser) แยกส่วน K-P-A, และตัวสร้าง HTML พรีวิวแผนการสอน

- src/exporter.ts
  * ตัวสร้างเอกสาร Word: บรรจุโค้ดสร้างไฟล์ .docx มาตรฐานราชการ 11 หัวข้อด้วย docx library 
    และระบบ Copy Rich-Text เข้าคลิปบอร์ด

- src/gemini.ts
  * Service สื่อสารกับ AI ผ่าน Cloudflare Worker Proxy

- src/config.ts
  * ไฟล์เก็บค่าคงที่ เช่น URL เริ่มต้นของ Worker Proxy และชื่อคีย์ LocalStorage

- src/types.ts
  * กำหนด Type และ Interface ทั้งหมดของระบบในรูปแบบ TypeScript

- src/style.css
  * สไตล์ชีตหลัก: Tailwind CSS, การตั้งค่า @font-face TH SarabunPSK, และ CSS สำหรับสั่ง Print A4

- public/data/curriculum.json
  * ฐานข้อมูลหลักสูตรแกนกลาง 2551/2560 ครบทั้ง 8 กลุ่มสาระฯ และปฐมวัย (70 มาตรฐาน, 2,598 ตัวชี้วัด)

- public/fonts/ (THSARABUN.TTF, THSARABUNBOLD.TTF, THSARABUNITALIC.TTF, THSARABUNBOLDITALIC.TTF)
  * ฟอนต์ TH Sarabun แท้ทั้ง 4 สไตล์ จำเป็นสำหรับการแสดงผลหน้าเว็บและพรีวิวเอกสาร

- package.json & package-lock.json
  * จัดการ Dependencies (docx, file-saver, vite, tailwindcss, typescript) และสคริปต์รันระบบ

- vite.config.ts
  * คอนฟิก Vite: ตั้งค่า base: './' เพื่อรองรับ GitHub Pages และ Build output

- tsconfig.json, tailwind.config.js, postcss.config.js
  * คอนฟิกการคอมไพล์ TypeScript และ Tailwind CSS

- public/.nojekyll
  * ป้องกัน GitHub Pages ประมวลผลด้วย Jekyll ทำให้โหลด Asset ของ Vite ได้ถูกต้อง


กลุ่มที่ 2: ระบบ Backend Proxy & CI/CD Deployment
--------------------------------------------------------------------------------
- worker/worker.js

- worker/wrangler.toml
  * คอนฟิกสำหรับการ Deploy Cloudflare Worker

- .github/workflows/deploy.yml

- README.md
  * คู่มือการใช้งานโปรเจกต์ ลิงก์ Live Demo และขั้นตอนการเปิดใช้งาน GitHub Pages

- .gitignore
  * กำหนดไฟล์ที่ไม่ต้องนำขึ้น Git เพื่อความสะอาดและความปลอดภัย


กลุ่มที่ 3: สคริปต์เครื่องมือพัฒนา (Development Tools - ไม่มีผลต่อหน้าเว็บ)
--------------------------------------------------------------------------------
- scripts/

    data_science.js, data_social.js, patch_science_social.js

กลุ่มที่ 4: ไฟล์ที่ไม่มีผลต่อการทำงานของเว็บเลย (Dead / Temp / Backup Files - ลบได้)
--------------------------------------------------------------------------------

  * เหตุผล: ระบบสร้างไฟล์ Word ผ่านโค้ดใน src/exporter.ts 100% ไม่มีการเปิดอ่านไฟล์นี้ ลบได้ทันที

- scratch/raw_data/ (curriculum-BackUp.json, และไฟล์ .txt 4 กลุ่มสาระ)
  * สถานะ: "ไฟล์สำรองและข้อความดิบ"
  * เหตุผล: เป็นข้อมูลดั้งเดิมตอนเตรียมหลักสูตร ไม่ได้เชื่อมโยงกับโค้ดหน้าเว็บ

- ตย

  * เหตุผล: บันทึกข้อความตัวอย่างที่ใช้ลองเทส ไม่ได้ถูกเรียกใช้งานในโค้ด

- .agentrules
  * สถานะ: "คอนฟิกเฉพาะ IDE"
  * เหตุผล: กฎการทำงานของเครื่องมือ AI ไม่เกี่ยวข้องกับโค้ดโปรเจกต์

- ReviewIDE.txt
  * สถานะ: "บันทึกประวัติการพัฒนา"
  * เหตุผล: บันทึก Log การทำงานตามคำสั่ง ไม่มีผลต่อ Logic หน้าเว็บ

- dist/
  * สถานะ: "Build Artifact"
  * เหตุผล: โฟลเดอร์ที่ได้จากการรัน npm run build ใช้สำหรับนำขึ้น branch gh-pages

================================================================================
[ข้อดี]:
1. สถาปัตยกรรมไร้ Server (Serverless/Static): ใช้งานได้ฟรีบน GitHub Pages ค่าดูแลรักษา 0 บาท
2. ฐานข้อมูลหลักสูตรสมบูรณ์ที่สุด: มีตัวชี้วัดครบ 100% ทุกกลุ่มสาระตั้งแต่ ป.1 ถึง ม.6
3. ความเสถียรของ AI: มี Proxy คอยหมุนเวียนคีย์และสลับโมเดลอัตโนมัติ ลดโอกาสล่ม
4. คุณภาพเอกสาร Word: สร้างแบบกำหนดหน่วย Twips ตรงตามแบบฟอร์มราชการไทยแท้

[ข้อเสีย / ข้อควรระวัง]:
1. ขนาดไฟล์ curriculum.json มีขนาดประมาณ 970 KB ต้องโหลดในการเปิดเว็บครั้งแรก
2. การตั้งค่า API Key ของ Worker ต้องทำผ่าน Cloudflare Secret เพื่อความปลอดภัย ห้ามเปิดเผยในโค้ด
